# Implementation

Labs that start from a blank topology and end with a working network.

Each one ships a design — addressing, wiring, device roles and the reasoning
behind them — together with skeleton configurations that carry hostnames,
interfaces and addressing and no protocols. The exercise is to build the rest.
A lab is finished when it passes the whole of its `verification.md`, failure
tests included, not when the first ping succeeds.

`configs/` holds the finished state, captured from the running lab and
sanitised.

The full list, with status, is in the [lab index](../README.md#lab-index).
