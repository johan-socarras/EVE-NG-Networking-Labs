# Discovery

Labs that start from a running network nobody documented.

Each one hands over console access and nothing else: no diagram, no addressing
plan, no description of what it runs. The configurations exist only as
startup-configs to load into EVE-NG. The deliverable is the documentation
itself — a topology recovered from CDP, LLDP and the routing tables, an
addressing plan, a map of which protocols run where, and a findings report of
what is misconfigured, undocumented or risky.

No discovery labs are published yet. The track and its format are defined here
so that the first one has a place to land.

The full list, with status, is in the [lab index](../README.md#lab-index).
